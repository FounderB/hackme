HackMe Setup
============

Official Windows installer for hackme.tech.

On the next page choose how you will use HackMe:

  Miner
    Join the public Useful PoW pool. GPU/CPU hashing, dashboard Mining tab,
    pool token preconfigured — one click to start.

  Orders (B2B)
    Local node for Dig (WASM) security fuzz campaigns. Dashboard opens on
    Orders. Includes hackme-fuzzing CLI (wizard + build) in the same folder.
    Hunt (AFL++/libFuzzer) runs on Linux miners — not in this Windows build.
    No mining worker is started.

Both profiles install the same core node. You can add the other profile later
from the Start menu shortcuts.

Pool / site: https://hackme.tech
Support: Telegram links on the website.
